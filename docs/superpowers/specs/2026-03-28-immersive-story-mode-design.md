# 沉浸式剧情模式重构设计方案

## 概述

将现有的剧情模式（NovelSceneRenderer + ChapterStoryRenderer）合并为统一的沉浸式剧情引擎，提供更流畅的视觉小说体验。

## 设计方案汇总

| 特性 | 选择 |
|------|------|
| 角色卡展示 | 渐变淡入/淡化 + 大立绘风格 |
| 场景切换 | 预览地图模式（迷你地图） |
| 旁白/动作展示 | 卡片式分开展示，动作卡片带箭头指向说话角色 |
| 整体布局 | 沉浸式（全屏背景 + 半透明浮动卡片） |
| 输入方式 | 快捷指令 + 自定义输入 |
| 多角色对话 | 跟随说话者切换立绘 |
| 剧情推进 | 混合模式（自由输入 + AI引导分支） |
| 历史记录 | 时间线模式，左侧边栏 |
| 实现方案 | 方案B：完全重构 |

## 核心组件

| 组件 | 职责 |
|------|------|
| `ImmersiveStoryRenderer` | 主容器，管理整体布局和状态 |
| `SceneBackground` | 全屏背景层 |
| `NarrativeCard` | 旁白/动作卡片，支持动画效果 |
| `DialogueBox` | 角色对话框 |
| `CharacterPortrait` | 大立绘，支持淡入淡出动画 |
| `SceneMapMini` | 场景预览地图（迷你版） |
| `TimelineSidebar` | 左侧时间线 |
| `QuickActionBar` | 快捷指令栏 |
| `FreeInputBar` | 自定义输入区 |

## 关键特性

### 1. 角色立绘动画
- 角色说话时：大立绘淡入（opacity 0→1, 500ms）
- 角色停止说话：大立绘淡化（opacity 1→0.3, 800ms）
- 切换说话者：当前立绘淡出 → 新立绘淡入
- 尺寸：高度约占内容区域的40-50%

### 2. 场景切换
- 左上角场景按钮点击 → 弹出迷你地图
- 地图显示场景拓扑关系
- 切换后背景平滑过渡

### 3. 时间线
- 左侧固定面板，可折叠
- 每回合记录：时间戳 + 简要描述
- 点击跳转可定位到对应对话

### 4. 快捷指令
- 预设按钮：看向、走向、拿起、说、询问、调查
- 点击快捷指令 → 自动填入输入框
- 下方支持自定义输入

## 组件结构

```
ImmersiveStoryRenderer
├── SceneBackground (全屏背景)
├── SceneMapButton (左上角场景按钮)
├── SceneMapMini (场景预览地图弹窗)
├── TimelineSidebar (左侧时间线)
├── ContentArea
│   ├── CharacterPortrait (大立绘)
│   ├── NarrativeCard (旁白卡片)
│   ├── ActionCard (动作卡片)
│   ├── DialogueBox (角色对话框)
│   └── InputArea
│       ├── QuickActionBar (快捷指令)
│       └── FreeInputBar (自定义输入)
├── ChoiceOverlay (AI分支选择弹窗)
└── RendererControls (底部控制栏)
```

## 数据流

```
用户点击快捷指令/输入
        ↓
   AI生成剧情
        ↓
  解析：旁白/动作/对话/选择点
        ↓
更新 dialogueHistory[]
更新 currentCharacter（说话者）
触发立绘动画
记录时间线
        ↓
检测是否需要分支 → 显示分支选项
```
